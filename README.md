# 📋 Form Validation

A contact form with **real-time validation**. Each field is checked as you type, with a clear error message or a green check mark, and the form won't submit until every field is valid.

## ✨ Features

- **Live validation** on every keystroke
- **Full name**: requires at least a first and last name; middle names, hyphens and apostrophes are allowed
- **Phone number**: must be exactly 10 digits
- **Email**: checked against an email pattern
- **Password strength rules**:
  - at least 8 characters
  - an uppercase letter
  - a lowercase letter
  - a number
  - a special character
- **Show / hide password** with the eye icon
- **Message**: live counter showing how many more characters are needed (minimum 30)
- ✅ Check mark for each valid field
- Submit is blocked, with a temporary "please fix error to submit" message, until everything is valid

## 🛠️ Built With
